# Running-an-election
A project to run an election using the Instant Runoff Vote (IRV) and Single Transferrable Vote (STV) counting methods. Adapted from a course at The University of Edinburgh.

The file irv.py runs an election using IRV. A file to run an election using STV is in progress. ballot_data.py contains some useful helpful functions to count votes at any preference in a given set of ballots and to generate random (valid) ballots for testing.

Software and packages used:
- python 3.13.7
- numpy 2.3.3
- matplotlib 3.0.2
